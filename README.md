# C++ Array-Based CRUD Operations

A menu-driven C++ program developed to practise basic CRUD operations using arrays and functions.

## Project Overview

This program allows users to manage a collection of integers through a simple menu-based interface.

## Features

- **Add:** Insert a new number into the array.
- **Search:** Find a specific number.
- **Update:** Replace an existing number.
- **Delete:** Remove a number from the array.
- **Display:** View all stored numbers.
- **Exit:** Close the program safely.

## Technologies Used

- Programming Language: C++
- Arrays
- Functions
- Loops and conditional statements
- Input validation
- Reference parameters

## Program Limitations

- Maximum storage capacity is 20 integers.
- Data is stored temporarily in memory.
- Numbers are not saved after the program closes.
- No database or file handling is implemented.

## How to Run

1. Download or clone this repository.
2. Open the `.cpp` file in a C++ IDE.
3. Compile and run the program.
4. Select an operation from the displayed menu.

## Learning Objectives

This project demonstrates the practical implementation of Create, Read, Update and Delete operations using fundamental C++ programming concepts.

## Project Type

Academic programming exercise.
